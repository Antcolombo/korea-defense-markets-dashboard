# Public Proof Checklist

- `/rotation` shows sourced point-in-time rotation signals.
- `/stock-report` and `/report/NVDA` generate a sourced single-stock PM report with markdown export.
- `/baskets` shows theme sponsorship without fake basket data.
- `/positioning` displays unavailable or entitlement-missing fields instead of imputed values.
- `/crowding` shows component-level score logic and excluded inputs.
- `/research/validation` reports hit rate, average forward return, sample size, and caveats.
- `/daily-note` stores source coverage, note status, input snapshot IDs, and excluded unavailable inputs.
- `/case-studies/korea-defense` uses the same framework as the rest of the terminal.
