# How To Read The Terminal

Start at `/rotation` to see sector and theme leadership. Confirm `dataStatus` and availability before reading a metric.

Use `/positioning` to inspect options, open interest, implied volatility, FINRA short interest, and missing entitlement fields.

Use `/crowding` to see the transparent score and excluded unavailable components.

Use `/research/validation` to test whether signals have forward-return support.

Use `/daily-note` only after checking source coverage and excluded inputs.
