# Future Integrations

The current architecture supports generated JSON outputs and provider ingestion scripts. Future integrations can add:

- AlwaysWatching.ai event database
- Additional public event feeds
- Licensed market-data APIs
- SEC EDGAR company facts expansion
- OpenDART corp-code mapping for Korean companies
- Supabase Postgres for persistence
- Scheduled ingestion jobs

Any future integration should preserve the same public-source, no-MNPI, no-investment-advice constraints.
